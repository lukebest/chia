## 3. 信息论视角：为什么代码是更好的对齐媒介

上一节定义了周期模型 $M$ 的三重身份，但还没回答最核心的问题：同样是向 RTL agent 传递设计意图，为什么一段可执行的周期模型代码，本质上比一份自然语言规约更有效？把两阶段流程放进信息论记账模型里拆解，背后有四个递进的机制。

### 3.1 数据处理不等式：对齐的投入点在哪里

假设探索目标与原始意图为 $G$，探索阶段产出周期模型 $M$ 与显式物理约束侧信道 $C$；RTL agent 在共享先验 $K$ 下只根据 $(M, C)$ 生成 RTL 实现 $R$。此时信息流动构成条件于 $K$ 的马尔可夫链 $G \to (M, C) \to R$。由**数据处理不等式（data processing inequality）**，必有：

$$I(G;R\mid K)\le I(G;M,C\mid K).$$

这意味着，RTL 实现 $R$ 对原始意图 $G$ 的对齐程度存在硬上界——它永远不可能超过“周期模型 $M$ 加约束侧信道 $C$”对意图的对齐程度。这直接给出两层洞察：

第一，**对齐的功夫应花在 $M$ 与 $C$ 上。** 既然 $(M, C)$ 是信息瓶颈，与其在成千上万行 Verilog/Chisel 里做人工审查，不如把精力集中在体量更小、可读且可运行的 $M$ 与 $C$ 上。原本端到端不可分解的大检查，由此被拆成两个可分别验证的半段：$G \leftrightarrow M$ 由探索 fitness 与人工审阅把关，$R \models M$ 由协同仿真机械判定。

第二，**凡是 $M$ 不表达的意图，必须显式进入侧信道 $C$。** 上式成立的前提正是上述马尔可夫性，即 $I(G; R \mid M, C, K) = 0$。若 RTL agent 同时读取自然语言文档，这一项就大于零，上界不再成立——文档可能补洞，也可能与 $M$ 冲突，因此工程上应遵守一条规则：**$M$ 是单一事实来源；自然语言只作注释；冲突时以 $M$ 为准，且冲突本身记为 $M$ 的缺陷。** 相应地，$M$ 不表达的 PPA 目标、时钟/复位策略、DFT 与功耗意图，若不进入侧信道 $C$，RTL 阶段在信息上不可能恢复它。“PPA 从探索主干中分离”的精确含义正是让 PPA 走显式侧信道 $C$——Design Conductor 2.0 发现人类审阅是主要瓶颈、唯一办法是“让人类设计者事先想清楚关键约束（PPA）” [5]，正是这一点的实践印证。

### 3.2 重新定义 $\alpha$：从同义反复到可检验假说

信息论模型用因子 $\alpha \ge 1$ 表示自然语言相对形式化代码的歧义开销，但若直接定义“$\alpha_{\text{code}} = 1$”就成了同义反复。为此，对任意通道 $X$（自然语言或代码），令接收消息 $x$ 后的残余歧义为 $A_X := H(S_e \mid x, K)$，将残余歧义压到 $\delta$ 以下所需的最短消息长度为 $L_X(\delta)$，定义 $\alpha_X(\delta) := L_X(\delta) / H(S_e \mid K)$。

- 对周期模型代码 $M$：在观测接口 $\mathcal{O}$ 上运行代码即可回答所有“下一拍会怎样”，故 $A_M = 0$；其 $\alpha_M \ge 1$ 来自建模样板，**大致是不随精度变化的常数**。
- 对自然语言：**我的猜测（目前只有旁证）是，$\alpha_{NL}(\delta)$ 会随精度要求上升（$\delta \to 0$）而急剧上升。** 对周期级交互（冒险、背压、仲裁的组合），要求越精确，自然语言越冗长且越不可靠。旁证包括：Design Conductor [4] 发现规约少了 CPI 那一行就会生成分支与前递性能退化的处理器；LLM-FSM [10] 将结构化 YAML 渲染为自然语言规约后，随着有限状态机复杂度上升，最强 LLM 的精度骤降；HLSPilot [11] 也直接指出自然语言表达与硬件设计意图之间存在“显著语义鸿沟”，转而用 C/C++ 配合 HLS 缩小差距。

### 3.3 核心洞察：把沉默的歧义变成可检测的分歧

把通道 $X$ 的残余歧义——更准确地说，是接收方据此形成的解释与 $S_e$ 之间的残余偏差——按“能否被现有 oracle 在激励下暴露”拆成可检测与沉默两部分：

$$A_X = A_X^{\text{detect}} + A_X^{\text{silent}}.$$

这意味着，代码的优势不只是“更少歧义”，更是**把沉默的歧义变成可检测的分歧**，因而设计观测接口 $\mathcal{O}$ 与激励覆盖率，就是在设计 $A^{\text{silent}}$ 的上界。

在自然语言通道中，没有可执行 oracle，agent 会悄悄选定一种解释而不报告，残余歧义几乎全部是 $A_{NL}^{\text{silent}}$，要到后端才以深层 bug 暴露——Zhang 等人的错误归因研究 [13] 也将“规约歧义（ambiguous specifications）”列为 LLM 生成 RTL 的主要失败根因之一。相反，用可执行 $M$ 做协同仿真时，信息上的歧义 $A_M$ 已为 0，剩下的只是 agent 误读或误实现 $M$ 造成的偏差：任何改变 $\mathcal{O}$ 上行为的偏差都会以分歧形式暴露为可检测部分，沉默部分只剩“激励未覆盖的输入”上的偏差；至于“$\mathcal{O}$ 之外的行为”，它按定义不在 $S_e$ 之内，只能经 $C$ 与 $\Delta$ 显式交代。

CHIA 的 CIRCT 案例 [1] 中的 `UNCLEAR` 门，正是同一原理在“没有可执行规约”时的替代品：`assess` 阶段枚举所有实质不同的合理修复方案，数量 $>1$ 且无依据时（说明 $H(\text{fix} \mid \text{issue}, K) > 0$，如 #8508 中“诊断并拒绝”与“扩展支持”同样合理）直接返回 `UNCLEAR` 拒绝盲目修改，对明确问题则用可执行脚本 `repro.sh` 与无 LLM 的 `verify` 阶段把关；软件领域的 ClarifyGPT [12] 用“多个候选代码不一致”检测需求歧义并生成澄清提问，结构完全同构。

### 3.4 新颖性把自然语言推入悖论区间

探索产出中真正有价值的新机制 $S_e^{\text{new}}$，按定义是先验未覆盖的，即 $I(S_e^{\text{new}}; K) \approx 0$。由信息论框架中的定理 4.1 与推论 4.2（悖论区间），对任意 $\alpha_{NL} > \alpha_M$（原框架默认代码一侧的 $\alpha$ 取 1），用自然语言传递这部分的成本必然高于直接写代码的成本。严谨起见，若发现是已知部件的新组合（$I(S_e; K) > 0$），可定义新颖比例 $\rho = H(S_e \mid K) / H(S_e)$，结论随 $\rho$ 增大而单调增强。

> **架构探索的产出，恰恰是模型先验覆盖不到的那部分；而这正是自然语言对齐必然亏本的区间——所以它只能以代码交付。**

简言之，**越是有价值的探索结果，越不能用自然语言交接。** 而探索过程本来就已经把候选方案写成了模拟器里的可执行代码，因此直接交接 $M$ 的边际成本极低。

### 3.5 信息守恒，付费者变了

信息论框架（命题 5.1）把第 $t$ 轮修正 $m_t$ 的信息量记为 $H(m_t) := H(S \mid K, m_{<t}) - H(S \mid K, m_{\le t})$——严格说这是该轮消除的不确定性，即条件互信息 $I(S; m_t \mid K, m_{<t})$，而不是消息本身的熵；收敛时伸缩求和得 $\sum_t H(m_t) = H(S \mid K)$。本文沿用这一记号，并按记账口径把它读作“每轮至少必须传输的信息量”：真实消息若有冗余，其描述长度只会更大。把第 $t$ 轮修正消息拆为 oracle 生成的 $m_t^o$ 与人工编写的 $m_t^h$，由链式法则，$H(m_t)$ 相应拆成 $m_t^o$ 消除的部分与“看过 $m_t^o$ 之后”$m_t^h$ 再消除的部分 $H(m_t^h)$：

$$m_t = (m_t^h, m_t^o), \qquad E_{\text{human}} = \sum_t H(m_t^h).$$

这意味着，虽然消除不确定性所需的总信息量守恒，但人类的精力开销只取决于无法由机器代劳的 $m_t^h$（$E_{\text{human}}$ 同样是记账量，是人工描述长度的下界）。

> **迭代对齐的总信息量是守恒的；可执行模型改变的是谁来付费：把人写的修正描述，换成机器算出的第一处分歧。**

有了 $M$ 作 oracle，“RTL 哪里不对”由 $m_t^o$（第一处分歧的指令/周期及对应 trace 片段）承担，由算力买单；人只需支付 $M$ 不能表达的 $C$ 与 $\Delta$，且机器通道带宽远高于人工。CHIA 的 `riscv_extensions` 案例 [1] 是最干净的实例：Spike 编译进仿真器做逐指令 lockstep，连跑数百万条 `riscv-dv` 随机指令，文档原话写道 **“No expected output is ever hand-encoded — the golden model is the check”**（没有任何手写期望输出——黄金模型本身就是检查）；分歧在发生的那个周期就被抓获，分歧 trace 直接作为 $m_t^o$ 交给 debug LLM 修复 RTL。

```text
         自然语言路线                         周期模型路线
人写:   规约 α_NL·H(S_e|K)                 人写/审:  M(≈H(S_e|K),常为探索副产品)
人写:   每轮修正 m_t^h                      人写:     C⁺ 与 Δ(因拆分而须额外说出的东西)
人写:   testbench 期望值 V_NL               机器生成: 第一处分歧 m_t^o(带宽≫人)
歧义:   大部分沉默 A^silent                 歧义:     大部分可检测 A^detect
```

## 4. 把账算全：分治什么时候更划算

当然，周期模型 $M$ 自身并不便宜——据 CHIA 论文，对齐后的 gem5 核相对基线有 1,520 行 diff [1]。为了算清分治何时划算，我们比较两条路线在 RTL 阶段的人类信息成本。由于两条路线对偶然复杂性 $S_a$ 享受同样的 agent 先验补全，$S_a$ 项两边相消。我们先把四个关键记账符号讲清：
- $V_{NL}$：直接路线中没有可执行模型，必须由人工编写的检查成本（如 testbench 期望值与断言）。
- $H(C_0)$：两条路线都必须交代的基本 PPA 目标（如“CPI $\le 1.5$、目标 1.6 GHz”等数字，$\alpha \approx 1$），属公共项，两边相消。
- $H(C^{+}) = H(C_{\text{split}}) - H(C_0) \ge 0$：**因拆分而必须额外跨越边界的约束信息**（每周期逻辑预算、物理反馈、工艺相关代理），这才是分治的额外约束成本。
- $H(\Delta)$：分治路线中显式写出合法周期级差异规则 $\Delta$ 的成本。

由此，直接路线成本为 $E_{\text{direct}} \approx \alpha_{NL} H(S_e \mid K) + V_{NL} + H(C_0)$。分治路线分两种情形：**情形 A（$M$ 是探索的副产品）**为 $E_{\text{split}} \approx c_{\text{ready}} + H(C^{+}) + H(\Delta) + H(C_0)$，其中 $c_{\text{ready}}$ 是把探索产出升级为 RTL-ready 周期模型的代价；**情形 B（$M$ 需要专门编写）**为 $E_{\text{split}} \approx H(S_e \mid K) + H(C^{+}) + H(\Delta) + H(C_0)$。在更严苛的情形 B 下，消去 $H(C_0)$ 后分治更划算的条件是（这里把写 $M$ 的 $\alpha_M$ 近似取 1；若计入建模样板，左边第一项变为 $(\alpha_{NL}-\alpha_M)H(S_e\mid K)$，下文结论不变）：

$$(\alpha_{NL}-1)\,H(S_e\mid K)+V_{NL}\;>\;H(C^{+})+H(\Delta).$$

这意味着，分治的盈亏边界由四项信息量共同决定，从中可以直接读出三条推论：
1. **新颖性越高越该分治**：左边随先验未覆盖的本质复杂性 $H(S_e \mid K)$ 线性增长。
2. **同一不等式也解释了 Design Conductor [4] 为何成功**：教科书级 5 级流水线使 $H(S_e \mid K)$ 很小，现成 Spike oracle 使 $V_{NL}$ 很小，不等式左边趋近于零，直接路线完全可行。框架同时解释了正反两种结果。
3. **分治的真实成本是“因为拆开而必须额外说出的东西”**：即 $H(C^{+}) + H(\Delta)$。物理耦合越强、合法周期级不确定性越多，分治优势越小——这正是后文要处理的边界条件。

而在情形 A 下，若探索本来就要做，$M$ 看似免费；**但如果探索是在低保真评估器（如 trace 驱动的 ChampSim）上做的，$c_{\text{ready}}$ 就会接近一次 `gem5_align` 的代价**——这正是第 2 节将子论点收窄为“多保真度级联”的原因。

最后加上机器成本：$E_{\text{total}} = E_{\text{human}} + \lambda\,C_{\text{machine}}$，$\lambda$ 为算力/token 相对人力的价格。分治路线把成本从人转给机器（据 CHIA 论文，cosim 占 `riscv_extensions` 总机时的 50%–66% [1]）；因此**我的猜测（目前只有旁证）是：随着 $\lambda$ 下降，分界线将持续向分治一侧移动。**
